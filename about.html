MINING123STUDIOs

Small, self-contained browser tools.

Who

I'm the developer behind MINING123STUDIOs, a hobbyist developer based in Bavaria, Germany, with a background in software development, mathematics, and engineering. I focus on creating high-quality open-source software and take a thoughtful approach to problem-solving. I'm currently beginning to pursue a degree in electrical engineering.

Outside of coding, I enjoy spending time with family and friends. I'm always open to contact, collaboration, and suggestions for improving my projects.

Most of what ends up here started as a question: what does this fractal look like, how fast can a browser crunch digits, what happens if this automaton runs forever. Building the thing was the excuse to find out.

The subjects drift: math and computation, language, cryptography, cellular automata, fractals, physics and plain play. Whatever the subject, it ends up as one page you can open and use.

What this is

A collection of small tools. Each one does a single job and stops there. Nothing leaves your machine: there are no accounts, and nothing is counted or stored. Pages run straight from file://, so the whole site also works offline once downloaded.

How the tools are built

Everything is written by hand in plain HTML, CSS and JavaScript. There is no framework and nothing to install before you can read the source: a tool is usually one page with a script tag in it. The single-file versions published here are assembled by a small Python script, which sits in the same repository.

Most tools are self-contained: one page, nothing fetched at runtime. The peer-to-peer ones are the exception; they need a signalling server to find each other, so they are the only pages that talk to the network.

It's all GPL-3.0. The full source is on GitHub, and any tool can be downloaded as a single file.
