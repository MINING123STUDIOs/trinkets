Spot the Odd One Out
Find the one item that's different from all the rest.

Categories: Visual (shapes/colors), Numbers (hidden rules), Words (category membership), Emoji (similar variants), or Mixed (random each round).

Settings: Grid size grows with "Grow" mode. Subtlety controls how obvious the difference is. Timer adds pressure. Decoys add near-miss distractors. Penalty type determines what happens on a wrong guess.

Scoring: +100 base per find. Speed bonus up to +200 if timer is on. Streak multiplier after 5+ correct in a row.
